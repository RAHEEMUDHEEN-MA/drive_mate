# DriveMate

One of my old college projects- 2023.

DriveMate was a vehicle assistance app with an AI-based engine complaint prediction feature using engine sound recognition (MFCC + KNN).

It also had features like finding nearby mechanics, on-road fuel delivery and a vehicle document wallet.

Just moving this here while cleaning up my laptop. Don't want to lose the old code, dataset and memories attached to it.

Nothing planned for this project. Just keeping it around.
